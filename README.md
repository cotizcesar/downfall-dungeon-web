# Downfall Dungeon

An isometric dungeon crawler in a single web page: a hundred floors, eight classes, one hero.

**Play it:** https://cotizcesar.github.io/downfall-dungeon-web/

Made for a computer (keyboard and mouse) or a controller. Phones and tablets are not supported.

This repository holds only the files the game needs to run. It is published from the game's source project.
